# Contributions: please fork first

This repository is shared publicly so you can read the source, download it and create your own fork. Public visibility does not grant write access to this repository.

To make changes:

1. **Fork** this repository into your own GitHub account.
2. Create a branch in your fork and make your changes there.
3. If you would like to contribute them back, open a **pull request** against this repository's `main` branch.

The repository owner decides which contributions to merge. Direct pushes to `main`, force pushes and deletion of `main` are blocked. Pull requests must pass the required checks and resolve review conversations before merging. The owner is currently the only account with write access; contributors do not need write access to submit a pull request from a fork.

Never include passwords, SSH keys, private configuration, real customer missions or device identifiers in a contribution. Use synthetic test data. Existing component licenses continue to apply.
